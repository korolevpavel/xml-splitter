# XML Splitter

**Разделитель XML-файлов по заданному количеству тэга**

Python-утилита для разделения больших XML-файлов на несколько валидных XML-файлов меньшего размера с заданным количеством элементов в каждом.

## Описание

XML Splitter — это легковесный инструмент, который позволяет эффективно обрабатывать большие XML-файлы, разделяя их на несколько меньших файлов. Каждый выходной файл содержит указанное количество определённых XML-элементов и сохраняет валидную XML-структуру с корректными заголовками и закрывающими тегами.

### Основные возможности

- **Разделение по количеству элементов**: задайте количество целевых тегов для каждого выходного файла
- **Сохранение структуры**: корректная XML-структура в каждом выходном файле
- **Эффективная работа с памятью**: потоковая обработка для работы с файлами любого размера
- **Гибкая настройка**: указание пользовательского тега для разделения
- **Валидный XML**: автоматическое добавление XML-декларации и корневых элементов

## Использование

### Базовое использование

```bash
python xml_splitter.py input.xml -t <tag_name> -c <count> -o <output_prefix>
```

### Параметры

- `input.xml` — путь к исходному XML-файлу
- `-t, --tag` — имя тега, по которому будет производиться разделение
- `-c, --count` — количество элементов в каждом выходном файле
- `-o, --output` — префикс для имён выходных файлов (по умолчанию: `output`)

### Примеры

**Пример 1**: Разделение файла products.xml по тегу `<product>`, по 100 элементов в каждом файле

```bash
python xml_splitter.py products.xml -t product -c 100 -o products_part
```

Результат:
- `products_part_1.xml` (содержит 100 элементов `<product>`)
- `products_part_2.xml` (содержит 100 элементов `<product>`)
- ...

**Пример 2**: Разделение файла данных по записям

```bash
python xml_splitter.py data.xml -t record -c 500 -o data_chunk
```

### Структура входного файла

Типичная структура XML-файла для обработки:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
    <item id="1">
        <name>Item 1</name>
        <value>100</value>
    </item>
    <item id="2">
        <name>Item 2</name>
        <value>200</value>
    </item>
    <!-- ... множество элементов ... -->
</root>
```

### Структура выходного файла

Каждый выходной файл сохраняет корневую структуру:

```xml
<?xml version="1.0" encoding="UTF-8"?>
<root>
    <item id="1">
        <name>Item 1</name>
        <value>100</value>
    </item>
    <!-- ... до указанного количества элементов ... -->
</root>
```

## Сценарии применения

- **Обработка больших XML-экспортов**: разделение больших выгрузок данных из ERP-систем (1C, SAP и т.д.)
- **ETL-процессы**: подготовка данных для пакетной загрузки в другие системы
- **API-интеграции**: создание пакетов данных для отправки через REST/SOAP API
- **Тестирование**: создание тестовых наборов данных из больших файлов
- **Параллельная обработка**: разделение данных для распределённой обработки

## Производительность

Скрипт использует потоковую обработку (`xml.etree.ElementTree.iterparse`), что позволяет обрабатывать файлы размером в несколько гигабайт без значительного увеличения потребления памяти.
